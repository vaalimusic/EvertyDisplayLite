EvertyDisplay Lite создаёт в Windows дополнительный виртуальный дисплей, который
ощущается как физический: через его границу можно проводить курсор, переносить
окна и выстраивать его относительно остальных мониторов.

## Возможности

- нативная пространственная топология Windows;
- Drag-to-Teleport для переноса окон;
- Live PiP с сохранением размера и положения;
- полноэкранный Viewport на Direct3D 11;
- OSD со схемой экранов, хоткеи и игровой режим;
- восстановление после сбоев драйвера и незавершённых операций;
- интерфейс на шести языках.

В официальной Lite-редакции **нет искусственного или лицензионного ограничения**
на число виртуальных дисплеев. Доступны многодисплейные схемы и сеточная
расстановка. Текущий подписанный драйвер MttVDD технически поддерживает до
**пяти активных виртуальных дисплеев** — программа предоставляет весь этот
диапазон и заранее останавливает шестую попытку понятным состоянием интерфейса.

## Сборка

Нужны Windows 10/11 x64, стабильный Rust MSVC, Visual Studio C++ Build Tools и
актуальный Windows SDK.

```powershell
cargo build --workspace --release
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
```

Workflow установщика загружает подписанный MttVDD 24.12.24 из официального
релиза разработчиков, проверяет закреплённый SHA-256 и Authenticode-подписи и
только после этого упаковывает его. Ключи подписи в репозитории не хранятся.
Локально установщик собирается командой `./scripts/build-installer.ps1` при
установленном Inno Setup 6. Готовая поддерживаемая сборка также доступна на
странице [EvertyDisplay](https://desk.everty.ru/evertydisplay).
